About

Why Yojana Setu exists

A CS002 Community Service build for the Digital & Financial Inclusion theme — problem-first, build-first, no slideware.

The problem

Eligible families miss benefits they've never heard of

India runs dozens of welfare schemes covering income support, healthcare, housing, pensions and education. But eligibility criteria are scattered across separate portals, written in dense administrative language, and rarely checked against a person's actual profile in one place.

As a result, families who qualify for real financial, housing or health benefits often never apply — not because they're ineligible, but because they never knew the scheme existed, or assumed it wasn't for them.

Methodology

How the matching engine works

No AI, no black box — every match can be traced back to a plain if/else rule.

1. Build a rules dataset, not a database

Each of the 22 schemes is a plain JavaScript object with a rules field — minimum/maximum age, income ceiling, allowed occupations, gender, state, and land ownership. No server, no SQL, nothing to host.

2. Read the user's profile from the form

Five fields — age, income, occupation, gender, state — are read directly from the form the moment it's submitted. Nothing is transmitted anywhere; the check happens in the same browser tab.

3. Filter, don't predict

A single function checks the user's answers against each scheme's rules and keeps only the schemes where every applicable rule passes. It's deterministic — the same inputs always produce the same matches, which makes the tool auditable.

4. Render results as a ledger

Matches are displayed with a plain-language benefit line, so a first-time user understands what they qualify for without decoding a scheme's official notification first.

Under the hood

Built to have zero deployment risk

Every piece is static — HTML, CSS and vanilla JavaScript. No build step, no server, no API keys to leak, nothing that can go down mid-demo.

HTML5 CSS3 Vanilla JavaScript (ES6) localStorage (bookmarks & feedback) Inline SVG icon system Zero dependencies Deployable on Vercel / Netlify / GitHub Pages
